## 📊 Featured Projects

### 💊 GLP-1 FAERS Adverse Event Analysis

Analyzed FDA adverse-event reporting patterns for **semaglutide and liraglutide** using a FAERS-derived dataset.

The project included data preparation and validation in **Python/pandas**, analytical queries and cross-validation in **BigQuery SQL**, and stakeholder-focused dashboards in **Tableau**.

Key areas explored included serious-report proportions, hospitalization and death reporting, adverse-reaction patterns, temporal trends, demographics, and the impact of using comparable observation periods.

[View project](https://github.com/juanssalazarga/GLP1_FAERS_Case_Study)
